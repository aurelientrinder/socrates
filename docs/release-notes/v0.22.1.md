## What's new in Socrates 0.22.1

**Fixes**
- Fixed the whole app window (including the sidebar and titlebar) scrolling on cheat sheets and math-heavy pages. The root shell now stays locked to the viewport while each page scrolls cleanly inside its own pane, and printing cheat sheets still spans multiple pages.

**Exam cheat sheets** (from 0.22.0)
- Make a cheat sheet for an exam from the Start dialog (Cheat sheet), a class page or a course card, with every line marked **you know this**, **shaky** (with a "Watch:" trap note) or **not seen yet**.

Installed apps update themselves.
