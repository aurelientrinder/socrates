## What's new in Socrates 0.18.0

**Regenerate any tutor message**
- Click **Regenerate** under any settled reply to ask the tutor to answer again. If you changed the model or thinking level in the picker since that message was sent, regeneration runs with your newly selected settings.
- Regenerating the latest reply runs right away; regenerating an earlier reply asks to confirm before clearing everything after it.

**Reliable live Gemini models**
- Discovered Gemini models (including the Gemini 4 family) are cached on disk per API key and kept across transient lookup errors or slow cold starts, so they no longer disappear when opening the app.

**Live SVG problem diagrams**
- When sketching helps a quiz question or practice problem (such as multi-body mechanics setups), the tutor draws an SVG diagram inline in real time between the problem statement and the answer area, with click-to-zoom support.

Installed apps update themselves.
