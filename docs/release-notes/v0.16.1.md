## What's new in Socrates 0.16.1

**Your sessions get their class colour automatically**
- A session whose title names one of your classes is now placed in that class on its own, so its icon in the sidebar takes the class colour and it shows under that class when you group by class. Sessions you filed by hand keep the class you chose.

**Know which version you're running**
- Settings > Data & updates now has an About section with the version number.

Installed apps update themselves.
