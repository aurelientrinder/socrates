## What's new in Socrates 0.17.0

**Socrates now runs on Gemini only**
- All tutoring, quizzes, exams, reading and dictation now go through Google's official Gemini library. Claude, OpenAI and the other providers are gone, so you only need a Gemini API key. If you were using another provider, add a Gemini key in Settings > Models & keys and pick a Gemini model.
- The model list now also shows the Gemini models Google makes available to your key, so a newly released model appears without an app update. It is cached for ten minutes, and if you're offline the built-in list is used.

**Cleaner tutor replies**
- When the tutor started to describe a tool it was about to use, for example "Let's call quiz...", that sentence could show up in the chat. It is now hidden, even while the reply is still streaming.

Installed apps update themselves.
